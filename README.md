# 🚀 Sundar Raj Kempe — AI-Powered Developer Portfolio

An **Awwwards-grade, production-ready** developer portfolio built for **Sundar Raj Kempe** (AI/ML Engineer & Java Full-Stack Developer). Designed with Next.js 15, React 19, and Framer Motion, featuring self-contained client-side AI tools—**no external paid API keys required**.

🔗 **Live Demo:** [portfolio-brown-nu-33.vercel.app](https://portfolio-brown-nu-33.vercel.app/)
---

## ✨ Key Features

* 🎯 **Hero Module:** Dynamic role typewriter switcher, live status badge (*"Open to Hiring 2026 Batch"*), and quick stats grid (VTU CGPA 7.0, 15+ Azure Badges).
* 👤 **About & Vision:** Integrated narrative highlighting education (GEC Bidar / VTU B.E. CS), KodNest Bengaluru offline Java training, and Japan MEXT Scholarship 2027 roadmap.
* 💻 **Interactive Skills Matrix:** Filterable technical proficiency matrix across AI/ML, Java, Web, SQL, and Cybersecurity.
* 📂 **Deep Case Studies:** Technical breakdowns for flagship projects including:
* **CyberGuard:** AI Malicious URL Detection
* **DormX:** Student Housing SaaS
* **Expense Tracker** & **Calendar View**


* 📐 **System Design Visualizers:** Interactive architecture diagrams, PostgreSQL ER diagrams, and microservice sequence flows.
* 📄 **Multi-Profile ATS Resume Builder:** Tailored resume generation for AI/ML, Java Backend, Full-Stack, and Cybersecurity roles with instant PDF export.
* 📊 **1-Click Recruiter Dashboard:** In-browser TF-IDF Job Description skill-match calculator and candidate snapshot.
* 🤖 **Client-Side AI Assistant & Copilot:** Localized NLP intent classification chatbot, voice control (Web Speech API), and automated cover letter generator.
* 🏆 **Gamified Achievements:** Unlockable achievement badges accompanied by interactive confetti effects.
* 🛠️ **In-Browser Admin CMS Drawer:** Live editing for hero text, contact info, and status badges—persisted via `LocalStorage` with a factory reset toggle.

## 🚀 Quick Start (Local Development)

### Prerequisites

Ensure you have **Node.js 18+** and **npm** installed on your system.

### Steps

1. **Clone the repository:**
```bash
git clone https://github.com/sundarkempe86-jpg/Portfolio.git
cd Portfolio

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. **Open in Browser:**
Navigate to [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) to view the application live locally.
